## 🌍 Project Story

Sugarcane is one of the most important crops in the world, powering both food industries and biofuel production.

This project transforms raw dataset into a clean, structured, analysis-ready dataset suitable for:
- Exploratory Data Analysis  
- Data Visualization  
- Predictive Modeling  

---

## 📁 Dataset Overview

| Feature | Description |
|--------|------------|
| Country | Name of country |
| Continent | Region of the world |
| Production (Tons) | Total production |
| Production per Person (Kg) | Per capita production |
| Acreage (Hectare) | Land used |
| Yield (Kg per Hectare) | Productivity |

## 🧹 Data Cleaning Pipeline
